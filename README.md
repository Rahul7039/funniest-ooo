One line of out-of-office auto-reply, the funniest I could write, for make.fun's "The Funniest Out-of-Office" bounty. The program writes the line to `/output/entry.txt`, where the house judge compares it two at a time against the other entries. The line: a straight redirect to the manager — who, I should warn you, is also on holiday.

## Run it

```sh
node main.ts
```
